v6.1 (2026-10-29)  SECURITY UPDATE. Design, products, prices, settings and the control-panel workflow are unchanged. Your data files (config.js, data/*.js) are NOT changed.
                   Control panel: data files are now read as plain data (the old loader executed them as code); data is checked before it is loaded, restored from a backup or published;
                   the GitHub token is kept in memory only unless you tick "Remember on this device" (no more silent session storage); clearer network / permission / conflict messages;

                   Website: stronger text escaping, product ids / image paths / links checked before use, unsafe links (javascript:) ignored, external links use noopener noreferrer,
                   Content-Security-Policy and Referrer-Policy added to every page.

                   per-phone and global flood limits, safer errors. ACTION NEEDED: paste the new Orders-Code.gs into Apps Script and deploy a NEW VERSION (see docs).

v6.0 (2026-10-23)  Checkout fix: total no longer shows NaN (missing delivery charge is treated as 0). Delivery ON/OFF switch (OFF = no address, no area, no delivery charge, pickup from showroom).

                   (turn on "Show QR photo" only after uploading your real photo). Floating WhatsApp button hidden on the checkout page.
                   Control panel: Save draft (kept on this device) and Review & Publish are now separate. The review list shows every change with tick boxes (photos, products, settings, coupons...);
                   untick anything you do not want to publish now and it stays in your draft. After publishing a list with check marks shows what went live.
